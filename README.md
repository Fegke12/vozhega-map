# Погнали в Вожегу! — Карта открытий

Интерактивная учебная экскурсия по Вожегодскому округу Вологодской области. Реальная карта, фотографии, наглядные опыты и небольшие задания помогают познакомиться с природой края через географию, химию, биологию и физику.

Проект подходит для самостоятельного знакомства с регионом, школьного урока и выступления с проектором. Откройте место на карте, пройдите исследование и сохраните наблюдения в полевом дневнике.

## Что можно исследовать

| Раздел | Тема | Интерактив |
| --- | --- | --- |
| География — «Под поверхностью» | Образование карстового озера | Последовательная схема растворения пород, появления пустот и заполнения котловины водой |
| Химия — «Секрет одной капли» | Растворённые вещества в воде, Погореловское озеро | Изменение концентрации солей и испарение литрового модельного образца |
| Биология — «Лес, который цветёт» | Памятник природы «Северные орхидеи» | Фотоатлас трёх видов орхидей и задание о сохранении растений |
| Физика — «Глубже — больше» | Пертозеро и давление воды | Погружение зонда, расчёт давления и переключение между давлением столба воды и полным давлением |

Каждый раздел состоит из трёх этапов: **место → исследование → наблюдение**. После правильного ответа открытие отмечается в дневнике. Там же можно записать собственные впечатления.

## Как пользоваться

1. Выберите точку на карте или раздел в списке исследований. Карст доступен как отдельная тематическая лаборатория.
2. Прочитайте описание, рассмотрите фотографию или схему и попробуйте интерактивные элементы.
3. Ответьте на вопрос и откройте полевой дневник, чтобы добавить заметку.

Карта поддерживает масштабирование и перемещение. Фотографии растений можно увеличивать. В разделе «Источники» собраны ссылки на публикации, авторов и лицензии изображений.

Для урока включите **«Режим показа»**: он увеличивает текст и рабочую область. Стрелки **← / →** переключают этапы открытого исследования, **F** запрашивает полный экран, **Esc** закрывает окно. Эти сочетания не мешают вводу заметок. Интерфейс адаптирован для телефонов.

Дневник сохраняется в браузере на текущем устройстве. Учётная запись для прохождения экскурсии не нужна; перенос заметок между устройствами не предусмотрен. Для загрузки картографической подложки нужен интернет.

## Запуск проекта

Проект написан на HTML, CSS и JavaScript. Сборка, установка npm-пакетов и серверная часть не требуются.

Из корня репозитория запустите:

```bash
python -m http.server 8080
```

Откройте [http://localhost:8080](http://localhost:8080). Стартовая страница перенаправит браузер в `dist/`. Для быстрого просмотра также можно открыть `dist/index.html` напрямую.

### Публикация на GitHub Pages

В репозитории выберите **Settings → Pages → Deploy from a branch → main → / (root) → Save**. Файл `.nojekyll` позволяет публиковать готовые статические файлы без обработки Jekyll.

Ссылку для окна «Поделиться» задаёт `SITE_URL` в `dist/content.js`. При смене адреса обновите эту константу и изображения `dist/assets/vozhega-qr.svg` и `dist/assets/vozhega-qr.png`, чтобы кнопка и QR-код вели на одну публикацию.

### Данные и логика

В `content.js` используются три основных массива:

- `STOPS` — разделы экскурсии: идентификатор, предмет, текст, координаты, факты, ссылки на источники, варианты ответа и итог наблюдения.
- `PLANTS` — карточки растений: русское и латинское название, фотография, описание, автор и лицензия.
- `SOURCES` — каталог публикаций с идентификаторами, названиями, ссылками и пояснениями.

`app.js` строит список исследований и метки из `STOPS`. Метку получают записи с полем `coords`; для карста открывается тематическая лаборатория. Координаты записываются в порядке **[широта, долгота]**. Ссылки раздела на источники связываются с `SOURCES` через их `id`.

Результаты и заметки хранятся в `localStorage` по ключам `vozhega-v2-<id>`. Изменения дневника синхронизируются между вкладками одного браузера. Заметка ограничена 1000 символами. Параметры опытов — концентрация, глубина, выбранное растение — находятся в текущем состоянии интерфейса.

Чтобы изменить тексты, задания или положение метки, редактируйте `content.js`. При добавлении нового типа опыта дополните соответствующую логику и отображение в `app.js`, а схему — в `scenes.js`. Самостоятельный новый раздел также потребует проверки счётчиков и подписей, рассчитанных на четыре исследования.

### Расчёты в опытах

- **Химия:** посетитель выбирает концентрацию от 0 до 35 г/л. Объём модельного образца — 1 л, поэтому масса растворённых солей в граммах численно равна выбранной концентрации. При испарении отображается остаток нелетучих солей.
- **Физика:** глубина меняется от 0 до 13,8 м. Давление столба воды рассчитывается как `p = ρgh`, полное давление — как `p = p₀ + ρgh`. Приняты `ρ = 1000 кг/м³`, `g = 9,81 м/с²`, `p₀ = 101,3 кПа`; результат выводится в кПа.
- **География:** SVG-разрез показывает последовательность карстового процесса. Профиль дна в физическом опыте также выполнен как учебная схема.

Параметры химического опыта задаёт посетитель. Значение 13,8 м для Пертозера взято из опубликованной съёмки. Фотографии растений служат атласом видов, а фотографии Воже, Святого и Долгого знакомят с озёрами Вологодской области.
