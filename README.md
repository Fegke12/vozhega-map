# Погнали в Вожегу! — Карта открытий

Учебная интерактивная экскурсия по Вожегодскому округу. География, химия, биология и физика объединены картой и полевым дневником.

## Открыть проект

Откройте `dist/index.html` в браузере. Для локального просмотра через HTTP выполните `python -m http.server 8080 --directory dist` и откройте http://localhost:8080. Для подложки OpenStreetMap требуется интернет.

## Для выступления

Кнопка «Режим показа» увеличивает текст и рабочую область. Стрелки ← → переключают этапы исследования. F запрашивает полный экран, если браузер разрешает его. Esc закрывает открытое окно. Дневник и заметки сохраняются в браузере устройства. Прогресс из первого макета переносится автоматически.

## Исходники

- `dist/content.js` — тексты, координаты, задания, источники и сведения о фотографиях.
- `dist/app.js` — карта, навигация, опыты и дневник.
- `dist/scenes.js` — учебные SVG-схемы.
- `dist/style.css` — оформление и адаптивная версия.
- `dist/assets/media/credits.json` — полные сведения об авторстве и лицензиях.
- `dist/assets/vozhega-qr.png` и `.svg` — QR-код опубликованной экскурсии.

## GitHub Pages

Содержимое `dist` готово для статической публикации. Для Pages выберите Settings → Pages → Deploy from a branch → main → / (root) → Save. Стартовая страница в корне перенаправляет на `dist/`. Сборка и серверная часть проекту не требуются. Если адрес публикации меняется, обновите `SITE_URL` в `content.js` и QR-код. QR в этой версии ведёт на текущую публикацию Sites, доступ которой требует учётную запись владельца.

## Данные

Пертозеро и Погореловское имеют картографические метки. Для «Северных орхидей» показана точка научного сбора 2012 года из Arctoa 2018, DOI 10.15298/arctoa.27.07. Границы территории требуют дополнительной сверки.

Название конкретного карстового озера из задания осталось неизвестным. География реализована как тематическая лаборатория. Солёность Погореловского и его тождество озеру Погорелово из отчёта ВНИРО требуют подтверждения. Опыт по химии — модель с задаваемыми пользователем значениями. Глубина Пертозера 13,8 м указана по опубликованной съёмке, рисунок дна условный.

Фотографии озёр показывают Воже, Святое и Долгое в Вологодской области. Фотографии орхидей показывают виды. Точные подписи, авторы, источники и лицензии доступны в разделе «Источники» на сайте. Учебные схемы созданы для проекта. Leaflet распространяется по BSD-2-Clause, текст лицензии включён.
